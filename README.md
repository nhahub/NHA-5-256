# Egypt Tourism Intelligence
### From Tourist Arrivals to Economic Insights

**DEPI Graduation Project | SQL Server · Power BI**

## Overview

Egypt Tourism Intelligence is a data analytics and business intelligence project developed as part of the **Digital Egypt Pioneers Initiative (DEPI)** graduation project.

The project analyzes Egypt's tourism sector using data on tourist arrivals, revenue, source markets, seasonality, and selected landmarks to uncover trends and support data-driven decisions.

## Objectives

- Analyze tourism arrivals, revenue, and growth trends.
- Identify key source markets and seasonal patterns.
- Explore the performance of selected landmarks and destinations.
- Develop evidence-based insights and strategic recommendations.

## 🛠️ Tech Stack

- **(if possible)Python scrpts:** for data cleaning, preparation.
- **Microsoft SQL Server:** Data cleaning, preparation, and management.
- **Power BI:** Data modeling, KPI development, and interactive dashboards.
- **Excel / CSV:** Data collection and preliminary preparation.

## 📊 Dashboard Sections

1. **Tourism Overview:** National arrivals, revenue, growth, and tourist nights.
2. **Source Markets:** Visitor origins, market share, and growth comparisons.
3. **Landmark Intelligence:** Dedicated analytical pages for selected destinations, such as the Pyramids of Giza, Grand Egyptian Museum, and Luxor.
4. **Opportunities & Strategy:** Seasonality analysis, market opportunities, and actionable recommendations.

## 📈 Key Performance Indicators

- Total Tourist Arrivals
- Tourism Revenue
- Year-over-Year Growth
- Average Spending per Tourist
- Average Length of Stay
- Market Share
- Seasonality Index

KPIs will be calculated where reliable, comparable data is available.

## 🔄 Project Workflow

Data Collection → SQL Data Preparation → Data Analysis → Power BI Modeling → Dashboard Development → Validation & Reporting

## 🚀 Expected Deliverables

- SQL Server database and data-preparation queries
- Interactive Power BI dashboard
- Documented KPIs and data sources
- Analytical report and strategic recommendations
- Final graduation project presentation
